# Prompt History

This folder contains archived prompt executions, reports, and historical prompt artifacts.

## Purpose

- Keep prompt outputs and historical prompt reports separate from active prompt definitions.
- Preserve past work, review notes, and audit artifacts.
- Avoid confusing these documents with the current prompt source files in `prompts/`.

## Usage

- Active prompts are defined in `prompts/`.
- Historical prompt reports and outputs are stored in `prompt-history/`.
- Do not add new prompt definitions here.
